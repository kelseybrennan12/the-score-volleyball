# Remaining Items

## Use When

- User says **"run remaining items"** (or "remaining items", "update remaining items", "refresh remaining list").
- User wants the [Remaining Items List](/docs/remaining-items-list.md) updated with current remaining work.

## What to Do

1. **Gather sources**
   - [/docs/stand-up-last.md](/docs/stand-up-last.md) — Section 4 (Scope / in-progress efforts), Section 6 (Spec to-do).
   - Product specs under [/docs/specs/product/](/docs/specs/product/) — each spec’s **Completion** and **Remaining**
     (and "Remaining — for team to consider" where present).
   - Efforts under [/docs/efforts/](/docs/efforts/) — efforts with `Status:` not Done/Complete, and efforts with
     unchecked `- [ ]` checklist items (grep for `- [ ]` and `## Status` in effort files).
   - [/docs/specs/process/](/docs/specs/process/) — developer-commands, quality-gates, and other process specs with
     remaining work.

2. **Build the list**
   - **By area of the app:** Group remaining work by area. Use these groups (and subsections as in the current
     artifact): Farm area (farm detail, overview, list, contacts, visits, schedule, farm audit data); Audit area (audit
     detail, audit workflow, non-conformance/CAP); Schedule area (master schedule, scheduling/blackout); Dashboard &
     manager oversight; Documents; Validus (tracking, category detail, program); Auth & access; Other pages (auditors
     list, long-term tracking). For each page/spec: one top-level bullet with the page name and spec link; under it,
     **sub-bullets** (indented with two spaces) — one sub-bullet per remaining item from Completion/Remaining and spec
     to-do.

3. **Write the artifact**
   - Set the header as in the current [remaining-items-list.md](/docs/remaining-items-list.md): title, _Generated by
     remaining-items skill…_, **Last updated:** today’s date (YYYY-MM-DD).
   - Keep output **concise and bulleted**; use spec and effort paths with markdown links. Do not duplicate long
     paragraphs — summarize.
   - **Overwrite** [/docs/remaining-items-list.md](/docs/remaining-items-list.md) with the full content.

4. **Confirm**
   - Tell the user the list was updated and point to `docs/remaining-items-list.md`.

## Output

- Overwritten [/docs/remaining-items-list.md](/docs/remaining-items-list.md) with the grouped remaining items.
- Brief confirmation in chat.
